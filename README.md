# parkir-otomatis
Berikut versi ringkasnya (di bawah 350 karakter):  This project is an Arduino-based automatic parking barrier system. It uses a servo motor to open/close the gate, a DC motor driver for mechanism simulation, and an LCD I2C to display status such as “PALANG TERBUKA” and “PALANG TERTUTUP”. It demonstrates basic automation and smart parking concepts.
